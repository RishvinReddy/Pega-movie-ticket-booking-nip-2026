# NIP Movie Ticket Booking
A Pega-based Movie Ticket Booking Management Application developed as part of the Pega National Internship Program.
## Project
- Project: Movie Ticket Booking
- Application: NIP-MovieTicket-RishvinReddy
- Case Type: Movie Ticket Request
- Platform: Pega
- Developer: Rishvin Reddy
## Overview
The application manages movie ticket booking requests from submission through
availability checking, cost calculation, customer confirmation, seat allocation,
booking processing, notification, SLA tracking, and routing.
## Case Lifecycle
1. Submit Movie Ticket Request
2. Check Show Availability
3. Calculate Booking Cost
4. Confirm Booking
5. Review Booking Details
6. Process Ticket Booking
7. Notify Booking Confirmation
8. Resolve Case
## Business Rules
- Validate requested ticket quantity
- Check available seats
- Calculate total booking cost
- Determine booking confirmation status
- Route requests according to show type
- Apply booking SLA
